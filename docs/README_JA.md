## 🌐 Uniskill とは？

Uniskillは、現代のAI支援開発ツール（Cursor、Claude Code、OpenClaw、Codex、Hermes、Opencodeなど）の間に存在するエコシステムの孤立と設定の断片化問題を解決するために設計された、クロスプラットフォームかつマルチエージェントのミドルウェア層です。

現在の環境では、様々なAIツールは互いに独立して動作しています。Cursor用に完璧な `.cursorrules` ファイルを作成しても、ターミナル内のClaude Codeはそれを全く認識しません。または、OpenClawに強力なMCPサーバーをインストールしても、他のローカル大規模言語モデルはそれを共有することができません。

**Uniskill は、この状況を終わらせます。**
> スキル（プロンプト / MCPサーバー / ネイティブプラグイン）を一度インストールまたは作成するだけで、システムがそれを即座に全互換フォーマットに変換し、あなたが所有する**全て**のAIアシスタントのコアに透過的にホットマウントします！

---

### 🔥 コア設計理念

- **1️⃣ Single Source of Truth（絶対的で唯一の情報源）**: 全てのローカルAI設定資産は収束され、`~/.shared-ai-skills/` のバックボーンディレクトリに一元管理されます。設定が失われることはもうありません。デバイスを変更する際も、この1つのディレクトリを同期するだけで完了します。
- **2️⃣ The Ultimate Translator（究極の全プラットフォーム翻訳機）**: ツールは共有された「意図」を自動的にフォーマットし、シンボリックリンク経由で配信します。Cursorへ提供するための `.cursorrules` を動的に生成したり、ClaudeへMCPコンソールをマウントするために `settings.json` を書き換えたりします。
- **3️⃣ Brownfield Migration（既存資産の強力な統合）**: `uniskill scan` を実行して、マシン全体のAI資産をワンクリックで嗅ぎ回ります。続いて `uniskill migrate` を使用することで、古いAIツール内に散らばっているレガシーなスキルパッケージを自動的に抽出し、重複を排除し、一元化された統合プールへ強制的に取り込みます。
- **4️⃣ OSに対する完全な非依存性**: 基礎となるディレクトリの差異を恐れる必要はありません。macOS、Linux、またはWindows環境において、シンボリックリンクラッパーやPath環境変数のシャドウイング技術を利用して、シームレスで静かな設定の上書きカバレッジを実現します。

## 🛠️ クイックスタート

### インストール

Uniskill はグローバルなNode CLIツールとして機能します。システムにNode.jsの実行環境がインストールされている必要があります。

```bash
# グローバルインストール（近日NPM Registryにて公開予定）
# npm install -g @robertsshu/uniskill 

# ソースコード検証用のインストール
git clone git@github.com:maomaocn/uniskill.git
cd uniskill
npm install
npm link
```

### 基本環境の初期化
初めて使用する際は、ルータープローブにあなたのローカル環境をプロファイリングさせてください：
```bash
uniskill init
```
*この操作により、コアとなるフォルダーが作成され、透過的な傍受マウントポイントが確立されます。*

### 操作の全体像
- マシン全体の既存AI資産の重複度をスキャンする：`uniskill scan`
- 既存ツール内のレガシースキルパッケージを統括マウントプールへ強制移行させる：`uniskill migrate`
- ユニバーサル共有スキルパッケージをインストールする：`uniskill install <パスまたはURL>`

## 🔮 私たちのビジョン
現在のパーソナルAIアシスタントツールは、分断された「群雄割拠」の時代にあります。Uniskillチームの目標は、単なる設定のコピーツールを作成することを超越しています。私たちは、**開発者ターミナルにおけるAI機能の統合コントロールプレーン（統制層）** を確立することを目指しています。この究極のオーケストレーション・アーキテクチャの解決に興味をお持ちであれば、PRやIssueを通じてこの基盤を共に構築することを歓迎します！
