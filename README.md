## 🌐 What is Uniskill? | 什么是 Uniskill？

Uniskill is a cross-platform, multi-agent middleware architecture designed to solve the fragmentation problem in modern AI-assisted development tools (Cursor, Claude Code, OpenClaw, Codex, Hermes, Opencode, etc.). 

Instead of writing and maintaining prompts, MCP (Model Context Protocol) servers, and skill configurations separately for every AI tool, Uniskill allows you to:
**Build/Install a skill ONCE, and mount it globally across ALL your AI assistants instantaneously.**

Uniskill 是一款跨平台、多智能体的中间件架构，旨在解决现代 AI 辅助开发工具（Cursor, Claude Code, OpenClaw, Codex, Hermes, Opencode 等）中的生态生态碎片化痛点。

它打破了各个工具各自为战的局面。你不再需要为每个 AI 工具单独安装提示词、MCP服务器和技能环境。Uniskill 使您能够：
**只需编写或安装一次技能，即可瞬间在您的所有 AI 助手之间实现全局挂载共享。**

---

### 🔥 Core Features | 核心特性

- **1️⃣ Single Source of Truth / 唯一真实来源**: Maintains prompts/rules centrally in `~/.shared-ai-skills/prompts/`.
- **2️⃣ The Ultimate Translator / 全平台终极翻译代理**: Automatically injects logic into `.cursorrules`, `claude settings.json`, and native frameworks.
- **3️⃣ Universal MCP Support / 通用 MCP 支持**: Centralized deployment for all Model Context Protocol tools.
- **4️⃣ Brownfield Migration / 历史资产收编器**: Intelligent scanner that finds your scattered AI configs and merges duplicate logic into the Uniskill pool.
- **5️⃣ OS-Agnostic / 无缝跨操作系统**: Seamless injection mechanisms whether you use macOS (symlink), Linux (alias config), or Windows (hard injections).
